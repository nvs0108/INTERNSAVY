# Level 1 Projects - INTERNSAVY Web Development Internship

Welcome to the Level 1 project submissions for the INTERNSAVY Web Development Internship. This directory contains two beginner-level projects designed to demonstrate fundamental skills in HTML and CSS.

│   ├── index.html

## 📌 Projects

### 1. Contact Form

A simple, responsive contact form built with HTML and CSS. It includes fields for:

- Name
- Email
- Message

**Features:**
- Clean layout
- Placeholder text and required validation
- Basic CSS styling for usability

**How to Run:**
Open `ContactForm/index.html` in your browser.

### 2. Personal Website

A basic personal portfolio webpage showcasing skills, projects, and contact information.

**Sections Included:**
- Introduction/About Me
- Skills
- Projects (can be updated with real links)
- Contact Info

**How to Run:**
Open `PersonalWebsite/index.html` in your browser.

## 💻 Technologies Used

- HTML5
- CSS3

## 🚀 Getting Started

To view the projects:

1. Clone the repository:
   ```bash
   git clone https://github.com/nvs0108/INTERNSAVY.git
   ```
2. Navigate to the `Level1` directory.
3. Open the desired project folder.
4. Launch `index.html` in your preferred browser.
